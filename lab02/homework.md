## Крок 4. Зелена метрика на хибному висновку

### Кейс A — C-03, спір (CUS-0004, TX-0402), годинник 2026-09-15

- **clean:** «Unfortunately, you cannot dispute this transaction today. The dispute window for this transaction has closed. … Dispute window: 60 days … Deadline: September 12, 2026»
- **lesson-02:** «Good news: **yes, you can dispute this transaction today**. … within **90 days** … Your deadline is October 12, 2026»
- **Доказ (вивід рушія, compare):**
  `tool.check_dispute_eligibility → eligible: false ≠ true`, `window_days: 60 ≠ 90`, `deadline: 2026-09-12 ≠ 2026-10-12`
- **Метрика:** faithfulness = 1.0 / 0.9 / 1.0, домен ✗.
- **Механізм:** дефект в інструменті; бот вірно переказує хибний результат, тому faithfulness зелена.

### Кейс B — C-05, конвертація 6 000 EUR (CUS-0005, tier 2)

- **clean:** «Spread: 0.9% … Spread applied: USD 58.70 … **Final amount: USD 6,463.04**»
- **lesson-02:** «Spread: 1.5% … Spread applied: −97.83 USD … **Your final amount: 6,424.00 USD**»
- **Доказ:** `tool.quote_fx → spread_pct: 0.9 ≠ 1.5`, `final_amount: 6463.04 ≠ 6423.91`
- **Два дефекти:** D20 — спред сусіднього тіру (інструмент); D25 — бот округлив 6,423.91 → 6,424.00 (генерація; імовірнісний, інколи до сотні).
- **Чому слабший приклад:** округлення суперечить інструменту, тож суддя знижує faithfulness.

## Крок 5. Faithfulness vs hallucination rate (курований контекст)

| Кейс | faithfulness (3 прогони) | hallucination rate (3 прогони) |
|---|---|---|
| C-03 | 1.0 / 0.9 / 1.0 | 1.0 / 1.0 / 1.0 |
| C-04 | 0.63 / 0.78 / 0.60 | 0.67 / 0.67 / 1.0 |
| C-08 | 0.73 / 0.71 / 0.73 | 1.0 / 1.0 / 1.0 |

На C-03 одна й та сама відповідь: faithfulness = 1.0 («ідеально»), hallucination rate = 1.0 («суперечить усім документам еталона»).
Причина — **знаменник**: faithfulness порівнює з тим, що бот отримав (хибний інструмент), hallucination — з курованим контекстом (правило + результат рушія).
Шкала: скрипт уже переводить score DeepEval у rate (clean = 0.00, ↓ краще), `1 − score` вручну не потрібен.
